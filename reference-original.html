About Sentinel
Project Expo — Security Log Analyzer

Sentinel is a client-side Security Operations Center (SOC) style dashboard that ingests server / system log files, classifies each entry by severity using pattern-based detection, and visualizes activity in real time.


It highlights failed login bursts, restricted-file access, port scanning, and other suspicious behaviour, then rolls everything up into live counters, time-series charts, and a threat-level distribution — with a one-click export once the review is complete.
